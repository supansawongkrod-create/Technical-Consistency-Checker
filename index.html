Gemini compares visible technical claims, numbers, standards, ports, interfaces, logos/icons when identifiable, and technically implied relationships against the references.

Strict reporting rule: Missing from the Sales Guide does not mean wrong. The system reports only (1) clear conflicts with the uploaded references, or (2) claims that are clearly technically false/impossible. If uncertain, it stays silent.
For this starter version, keep the total selected files small enough for a Vercel request (roughly a few MB total). PDFs work best for Sales Guides/Datasheets because PDF inputs preserve both extracted text and page images.
